# Soutenances 2026 — Business Project & Mémoire d'expertise

> Deux présentations, **20 minutes chacune**, livrées en **PPTX + PDF** (construites directement, prêtes à projeter).
> Ce dossier contient : le deck exporté, un **Design System complet + contenu** par présentation, le **script oral** par slide, et un fichier de script par slide.

---

## 1. Ce qui est livré

Les decks sont construits directement en **PowerPoint (.pptx)** et exportés en **.pdf** :
- Le **.pptx** est éditable (tu peux ajuster un mot, insérer une capture).
- Le **.pdf** a une mise en page figée, idéale pour projeter (aucune police à installer).

**Polices utilisées : Century Gothic (titres) + Calibri (corps)** — livrées avec Office, donc rendu identique sur n'importe quel poste, y compris une machine de l'école. Elles évoquent la marque DreamWeave (Quicksand + Nunito) tout en restant 100 % portables. Si tu présentes depuis ton PC et veux le match exact de la marque, on peut installer Quicksand + Nunito et les embarquer dans le fichier.

## 3. Comment répéter / éditer

- **Répéter** : ouvre `Script oral - …md` (ou le mode Présentateur de PowerPoint : les mêmes textes sont dans les notes de chaque slide). Le minutage cumulé est indiqué à chaque slide.
- **Éditer** : ouvre le `.pptx`. Pour changer le thème global, `00_DESIGN-SYSTEM.md` donne toutes les valeurs (couleurs HSL + hex, typo, gabarits).
- **Insérer une capture** : sur la slide DreamWeave, remplace le cadre gris « Capture à insérer » par une vraie capture de l'app.
- **Re-générer** : le deck est produit par un script `pptxgenjs` (côté outillage) ; me redemander si tu veux une variante.

---

## 4. Règles non négociables (les deux decks)

- **20 min** chacune. Minutage cumulé indiqué dans le script oral.
- **Zéro em-dash** (`—`) dans les textes affichés. Zéro copy AI-slop (« seamless », « révolutionner », « next-gen »).
- **Jamais 3 cartes identiques** en colonnes égales — varier les gabarits.
- Chaque chiffre du Business est **adossé à une source** (voir slide Sources) ou à une preuve de réflexion assumée.
- Regarde le jury, pas les slides. Les slides sont un appui, pas un prompteur.
